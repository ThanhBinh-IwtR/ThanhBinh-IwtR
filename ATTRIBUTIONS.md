# Asset credits

- The README is written by hand in Markdown/HTML.
- `assets/hero.svg`, `assets/navisight.svg`, `assets/visl.svg` and `assets/kicm.svg` are original hand-editable SVG illustrations made for ThanhBinh-IwtR / Tabi. Colours and animation timing are CSS at the top of each file. Brand ownership remains with its respective owner.
